# POWDER · 无界山域

一个原创的 3D 自由滑行生存游戏。无限山地、360° 转向、沿坡面扩散的雪崩，以及连续变化的昼夜与风雪。没有固定跑道、左右边界或强制前进方向。

## 本地运行

Windows 双击 `start-game.cmd`，或在项目目录执行：

```sh
npm install
npm run dev
```

打开 <http://localhost:5173/>。需要 Node.js 20.19+ 或 22.12+、支持 WebGL2 的浏览器与硬件加速。运行时素材、模型和声音全部在本地，不依赖素材网站。

## 无限山域

八类地貌相互连接：高山粉雪盆地、针叶林坡、陡峭雪槽、冰川、风蚀山脊、峡谷台地、冰湖雪原和聚落谷地。大尺度山峰、区域坡形和局部起伏共同构成实际可滑行的二维高度场，不能以单个“前进距离”重建世界。

- 地形和物件由种子及世界坐标决定，折返仍是同一片山域。
- 首页「新的山域」生成新种子，「重新开始」沿用本局种子。
- 速度由坡度、朝向、惯性、雪面摩擦与动作决定。可以横切和掉头，借惯性短暂上坡；撑杖不能无限爬陡坡。
- 四叉树地形由 Worker 流式生成；局部渲染原点重定位，物理使用双精度世界坐标。必要近景就绪前不进入缺失区块。
- 植被与障碍按地貌分布，不按车道排队；已收集物品不会因为区块卸载而重新出现。
- 自然坡唇会让雪板脱离地面，弹道与落地检测使用真实世界高度。

## 操作

| 操作            | 键盘 / 鼠标                      | 触屏                |
| --------------- | -------------------------------- | ------------------- |
| 自由转向        | A / D 或 ← / →                   | 摇杆左右            |
| 撑杖 / 压低身体 | 地面 W 或 ↑                      | 摇杆上推            |
| 刹车            | 地面 S 或 ↓                      | 摇杆下拉            |
| 跳跃            | 点按 Space                       | 点按跳跃            |
| 前后空翻        | 空中 W / S，长按 Space 或 F 后翻 | 前翻 / 长按跳跃     |
| 左右滚转        | 空中 Q / E                       | 独立左翻 / 右翻按钮 |
| 冲刺            | 按住 Shift                       | 按住冲刺            |

松开转向后不会回到中线。松开空翻键会自动回正，安全落地才兑现特技分数。1 / 2 / 3 圈分别奖励 150 / 450 / 900 分，双轴混合技巧加成 25%。失稳后按离地高度恢复 1 / 1.8 / 2.8 / 4 秒。

## 雪崩、昼夜与天气

雪崩有世界位置、预警时刻和沿坡面推进的覆盖区域；山脊会阻挡上行，横切可离开正面。事件至少预警 10 秒，后续事件频率随生存时间增加。危险只来自实际覆盖，不会因为抽象倒计时耗尽而直接失败。持续深度卷入才结束，护盾提供脱离窗口，企鹅和冲刺保留保护与机动作用。

首页选择清晨、正午、日落或夜间出发。现实时间 24 分钟完成一轮昼夜；晴朗、薄云、低云雾与风雪以至少 60 秒的连续过程过渡。暂停、设置和失去窗口焦点都会冻结游戏时间。太阳、月光、天空、雾、阴影、反射和窗光同步变化，夜间自动开启装备照明。

地形雷达显示周围起伏、朝向和雪崩位置。HUD 显示累计滑行距离、下降高度、区域、坡度、时间、速度与道具。

## 写实画质与素材

| 档位 | 材质             | 主要效果                                            |
| ---- | ---------------- | --------------------------------------------------- |
| 极致 | 雪岩 4K，其他 2K | 三层级联阴影、GTAO、遮挡光束、Bloom、首页景深、FXAA |
| 精细 | 2K               | 单层阴影、半分辨率 GTAO、Bloom、FXAA                |
| 流畅 | 1K               | 环境反射、接触阴影、简化地形与粒子、直接渲染        |

新存档桌面默认极致、触屏默认流畅；已有设置保留，旧 `medium` 映射为精细。镜头动态开关和系统减少动态偏好生效。

七组 Poly Haven CC0 贴图已下载并加工为本地资源，总计约 188 MiB。必要材质失败会禁用开始并提供重试；可选贴图和 HDR 失败使用备用表面。浏览器只加载当前档位，切换成功后释放旧纹理。作者、许可、下载版本、加工方法与 SHA-256 见 [素材说明](CREDITS.md) 和 [素材清单](public/materials/manifest.json)。新地形与天气均为程序生成，没有新增外部素材许可。

## 存档与兼容

金币、已解锁服装、音效和画质沿用当前 localStorage 存档。累计 100 / 300 金币解锁蓝色 / 紫色装备，换装不扣币。原跑道纪录保留，开放山域纪录分开统计。清除网站数据会清除本机进度；没有云存档、联机或排行榜。

`SkiGame` 的启动、暂停、恢复、重置和事件接口保持；`SkiWorld` 保持渲染、换装、画质和资源就绪接口。新增 `sampleTerrain(x,z,seed)` 统一服务物理、地形、雪崩与物件。旧一维地形辅助函数仅保留兼容，不再参与当前玩法。

## 构建与验收

```sh
npm run build
npm test
# 先在另一个终端运行开发服务器
npm run test:browser
npm run test:soak
```

浏览器验收使用 Playwright 和 Windows Edge，包括真实键盘、触屏、90 秒探索操作、八类场景及四个时段截图、加载失败与存档迁移。长期运行脚本持续 15 分钟，再对三档画质各采样 30 秒。证据输出至 `work/freeride-qa`。历史跑道脚本不作为新版验收入口。

升级前存在两项特技计圈测试失败：零散短按与自动回正累计、完整反向转圈计分。特技计圈逻辑独立保留，失败必须在验收结果中显式记录，不能作为新功能的通过证据。

本机 AMD 集成显卡精细档 1080p 的目标为持续 30 FPS；极致档记录真实平均和 P95 帧时间，不承诺固定帧率。发布前先按用户要求推送实现，再进行最终验收；验收修复也同步提交。

## 结构

| 模块                                     | 职责                                 |
| ---------------------------------------- | ------------------------------------ |
| `mountain-field` / `terrain-patch`       | 确定性二维高度场、地貌、四叉树与接缝 |
| `infinite-terrain` / `terrain-worker`    | 异步流式地形、缓存及回收             |
| `game` / `trick-mechanics`               | 自由滑行、碰撞、特技和恢复           |
| `spatial-entities` / `avalanche-field`   | 世界物件与空间雪崩                   |
| `world-weather` / `environment`          | 昼夜天气、天空和照明                 |
| `world` / `materials` / `postprocessing` | 场景、PBR 资源与后处理               |
| `main` / `input` / `ui` / `save`         | 页面流程、操作、导航与存档           |

不包含步行攀登、缆车、建造和联机功能。静态构建位于 `dist`，必须通过 HTTP 服务打开；本次不部署服务器。
