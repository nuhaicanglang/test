# POWDER · 雪境大冒险

一个原创的 3D 无尽滑雪游戏。穿越起伏的雪山和松林，冲出陡峭坡顶，在高空完成多轴翻转，稳稳落地后逃离身后的雪崩。

## 开始游戏

Windows 双击 `start-game.cmd`，服务器就绪后会自动打开浏览器。游戏地址为 <http://localhost:5173>；游玩时请保持启动窗口运行。

也可以在项目目录运行：

```sh
npm install
npm run dev
```

需要 Node.js 20.19+ 或 22.12+，以及支持 WebGL 2 的现代浏览器。首次安装依赖需要网络；游戏运行时的模型、画面和音效都在本地生成，不依赖在线素材服务。

## 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 左右转向 | A / D 或 ← / → | 左右按钮 |
| 跳跃 | 轻按空格或 ↑ | 轻点跳跃 |
| 前／后空翻 | W / S；长按空格或 F 也可后翻 | 按住「前翻」／「跳跃 / 后翻」 |
| 左／右翻滚 | Q / E，可与前后空翻同时按 | 切到「翻滚」，再按左右按钮 |
| 冲刺 | 按住 Shift | 按住冲刺 |
| 暂停／继续 | Esc 或 P | 暂停按钮 |

雪道包含上坡、波谷和大落差飞坡，冲过陡峭坡顶会自动起飞；首个自然飞坡正常速度可离地约 34 米、腾空约 3 秒。上坡会减速，下坡会加速，也可以提前冲刺获得更长的飞跃。石块和横木可以跳过，普通跳跃无法越过松树，高空飞跃可以越过树冠。金币路线始终留有通路。

空中完成的整圈越多，分数增长越快：1 圈 150 分、2 圈 450 分、3 圈 900 分，同时完成前后空翻与左右翻滚再加成 25%。空中面板显示高度、时间和待兑现得分。松开旋转键会自动回正，请提前留出着陆时间；只有安全落地才能兑现技巧分数，失败会清空本次技巧和连击。

失稳着陆后按本次最高离地高度分档摔倒。趴地期间无法转向、跳跃或冲刺，雪崩还会持续追近，恢复后有短暂保护：

| 最高离地高度 | 摔倒时间 | 立即损失的雪崩距离 |
| --- | --- | --- |
| 低于 4 米 | 1 秒 | 5 米 |
| 4 至不足 10 米 | 1.8 秒 | 9 米 |
| 10 至不足 20 米 | 2.8 秒 | 14 米 |
| 20 米及以上 | 4 秒 | 20 米 |

## 游戏内容

- 连续生成的起伏雪道、松林、木屋、旗标和雪山。
- 自由横移、前后空翻、左右翻滚、混合技巧、跳台和能量冲刺。
- 每 360 米一组不同幅度的起伏飞坡，带坡顶引导标记与距离预告。
- 雪崩追赶与渐进难度，分档摔倒、趴地恢复和起身保护。
- 约每 360 米一个护盾、磁铁或 8 秒企鹅伙伴，安排在落地后的缓坡；约每 720 米一个人工跳台。金币沿短路线分组出现。
- 距离、速度、金币、技巧任务与每局结算。
- 累计 100 / 300 金币解锁蓝色／紫色服装，选择服装不会扣除金币。
- 本地保存纪录、累计金币、已选服装、音效和画质设置。
- 暂停、重开、返回首页、全屏、触屏控制；切换窗口会自动暂停。
- 程序合成的风雪、跳跃、金币和事件音效；晨曦与暮色随距离变化。

本地存档位于当前浏览器的 localStorage。清除网站数据会同时清除纪录。此版本没有联网排行榜或云端账户。

## 构建与验证

```sh
npm test
npm run build
npm run preview
```

`dist` 是可部署的静态网站。请通过 HTTP 服务访问，不要双击 `dist/index.html`。

自动化验证覆盖地形连续性、世界坐标弹道、多轴技巧计分、分档摔倒、输入、角色姿态、存档和实体回收。安装了 agent-browser 的开发环境还可在开发服务器启动后依次运行 `node scripts/browser-smoke.mjs`、`node scripts/browser-air-smoke.mjs` 和 `node scripts/mobile-smoke.mjs`，验证桌面操作、高空实际帧循环与手机指针控制。这些脚本使用独立的 `powder` 浏览器会话。

## 结构

| 文件 | 职责 |
| --- | --- |
| `src/game.js` | 独立于渲染的物理、生成、碰撞和计分规则 |
| `src/terrain.js` | 起伏坡面、高度、斜率、曲率与飞坡预告 |
| `src/input.js` / `src/pose.js` | 双轴输入与围绕身体中心的旋转、摔倒姿态 |
| `src/world.js` | Three.js 场景、相机、地形、实例化松林与粒子 |
| `src/models.js` | 原创程序化角色、道具和场景模型 |
| `src/main.js` | 输入、固定步长游戏循环与页面流程 |
| `src/ui.js` / `src/style.css` | 响应式中文界面 |
| `src/audio.js` | Web Audio 合成音效 |
| `src/save.js` | 存档与服装解锁 |
| `tests` | 游戏规则与存档测试 |

素材与依赖说明见 `CREDITS.md`。
